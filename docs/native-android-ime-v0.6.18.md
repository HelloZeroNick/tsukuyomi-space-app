# Android 输入法与 Room 交互修复

0.6.18+24 / v0.6.18-beta.1。反馈设备为红米K90、骁龙8至尊版；当前未连接该真机。

## 输入法

键盘出现时，快捷建议从聊天Column中移除，原来的无键输入区与其他Padding按位置匹配，导致EditableText重新创建、文本输入连接断开。新的稳定输入槽键保留编辑器、焦点及连接；同步状态、错误提示和附件变化不会重新创建输入框。

另修复草稿回写：相同文本不再通过`.text`赋值清除选区与中文组词范围。账号／站点切换和确实不同的草稿仍会更新。小高度横屏输入时折叠顶部控件，确保提示、输入和发送按钮不溢出；收起键盘后恢复导航。

## Room 绘制

- 保留底部导航安全区，键盘动画不反复改变舞台尺寸。复用输入数据相同的CharacterStage；主题、像素密度、窗口大小、角色设置、城市和音乐状态仍能更新，动作、呼吸、口型及全屏继续共享资源。
- 手机合成预算根据实际Raster耗时和屏幕刷新率调整，避免仅依据角色30fps的33.3ms预算判断120Hz界面。累计8个超预算帧后分档降为原合成预算75%／50%，上限与下限有界；连续180个健康帧逐步恢复。它调整角色合成表面，不重载纹理，两张2048图集仍为32MiB RGBA8数据。
- 只看Raster压力调整合成预算，单独的UI耗时尖峰不会降低细节；隐藏／后台不累计，桌面预算保持原设定。原有角色帧率限制和后台暂停保留。

Flutter的[Picture.toImageSync文档](https://api.flutter.dev/flutter/dart-ui/Picture/toImageSync.html)说明图像句柄同步返回、栅格化在后台执行；本次没有把它解释为CPU同步回读，也没有替换原有遮罩、混合与着色器路径。

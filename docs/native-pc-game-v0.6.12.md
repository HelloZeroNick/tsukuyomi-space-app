# 原生性能、PC 全屏与移动端游戏修复 · 0.6.12+18

本次问题按用户补充分开验证：Room 动作抖动发生在 PC；辉夜快跑背景音乐消失及乘坐彩叶卡死发生在移动端。

## 修改

- Windows、macOS、Linux 共用导航栏增加窗口全屏按钮，窄窗口通过菜单进入。F11 切换，Esc 退出；macOS 同时支持 Ctrl+Cmd+F。窗口状态随路由保留，并同步系统全屏操作。移动端不初始化窗口插件。
- Room 静态背景与角色分别缓存绘制，角色动作限制在固定裁剪区域内，背景、导航和控件不参与动作变换。真实 Cubism 回归逐项触发八种动作，比较背景像素与布局位置。
- 游戏工程中的上、下按键条件引用了自身，乘坐广播执行时递归无法结束；下键条件还绑在错误循环上。修复引用与绑定，并移除飞行状态中与按键无关的持续向上位移，统一上下边界。加载时预检条件图，拒绝循环引用和过深嵌套，防止无效工程进入 UI 线程执行。
- Android 游戏的多声音播放器不再逐个争夺音频焦点，背景音乐与音效可以混音；iOS 使用支持混音的 playback 会话。暂停、恢复和音量仍由游戏控制。首次播放失败展示可见提示。
- Android 发布前的原生探针实际播放游戏音乐与音效，检查 BGM 未被中断，再验证暂停与恢复；此探针使用零音量，验证播放状态，不替代真机听音。

## 页面和 Live2D 性能

- 全站季节背景与前景分开绘制缓存；导航和菜单使用带季节纹理的半透明底色，去除每次滚动都要读取背景的实时模糊。继续保留原配色、纹理和分组导航。
- 站内素材图和网络图按显示尺寸、设备像素比解码，最长边限制 2048，防止缩略图占用原图级别的内存；图片地址校验与加载失败回退保留。
- 流式回复的固定问题气泡不再随每次片段重建；消息列表仍使用原有惰性加载、稳定 ID、完成后的 Markdown 缓存与 32ms 合并刷新。
- Cubism 网格一次批量读取，保留 Dart 网格对象及原生 UV、索引、位置缓冲。Core 更新后的变形标志驱动顶点缓存，染色着色器复用，参数仅在染色值改变时写入。
- 自动/省电画质按最长边 2048 解码角色纹理，原站两张 4096² 纹理的 RGBA 大小从 128MiB 降为 32MiB；完整画质仍加载原始纹理。切换画质异步重新加载，过期加载结果销毁，资源文件保持原样。
- 大视口默认对连续的普通混合绘制段限制分辨率；加色和乘色继续直接绘制在实际目标上，保留顺序与透明度，避免整角色离屏合成改变眼睛高光。遮罩、反向遮罩和染色都走相同测试。原生部分后端忽略网格的颜色矩阵，改为计算同一乘色/屏幕色公式的缓存着色器，并比较明确颜色、UV、半透明纹理与原始图像着色器。
- 默认电脑 60fps、手机 30fps，并根据帧耗时降频。使用绝对截止时间调度，修复 90Hz / 144Hz 屏幕因逐帧取整而长期低于目标帧率的问题。离开页面、进入后台、最小化窗口暂停；恢复后不补算停顿时间。
- 设置 → 角色中新增自动、省电、完整分辨率，以及自动/30/60fps，均保存到本地配置并提供中、日、英三种语言。完整分辨率会恢复原有绘制量。
- Android Release 原生探针增加普通/遮罩/反向遮罩/染色/加色/乘色的像素对比，并输出帧耗时；CI 模拟器的帧耗时只用于诊断，不当作手机性能验收。

同机三轮对比和原始数据见 [性能报告](native-performance-v0.6.12.md)。GPU 硬件验收目标是用户报告的 9070、4060 和 Android 手机；当前本地设备是 macOS，不能把本地 CPU 或 Raster 指标当作这些显卡的占用率。

## 验证

本地静态分析及格式检查通过，发布工具 38 项、Agent 打包工具 3 项通过。窗口、游戏和更新/导航专项回归通过，真实 Cubism 的八种动作背景像素回归通过。macOS Release 实际打开后验证全屏按钮、F11、Esc、Ctrl+Cmd+F，以及全屏中 Room → 中枢的页面切换；测试结束恢复普通窗口并退出应用。Release 内两种架构的 Agent 运行时清单及深层签名校验通过。

最终本地完整回归为 795 项通过、37 项可选环境检查跳过；原生 GPU 探针验证 30 帧眨眼及 14 个染色网格，颜色、UV、半透明、遮罩和混合均通过。自动化测试不能替代用户报告设备上的显示驱动、系统音频和安装交互验收；Windows / Linux 真实窗口和 Android / iOS 真机听音尚未验证，iOS 发布包仍需自行签名。

# Room 异步绘制与辉夜快跑连续性修复

0.6.20+26 / v0.6.20-beta.1。沿用原后端、聊天记录、2048纹理及关闭鼠标追踪；本次没有连接红米K90真机。

## Room

旧Room绘制在CustomPainter.paint中逐帧记录网格、生成离屏图片并合成。新场景把模型更新、帧准备和展示分开：模型更新后捕获完整不可变绘制列表，普通混合组异步转成图片；目的混合组保留绘制列表，继续与房间背景正确混合。所有组完成后一次替换展示帧，避免口型、遮罩和身体来自不同状态。

只允许一个帧任务在途，新更新合并到最近状态；GPU仍在准备上一帧时，场景时钟跳过无用的Cubism计算。展示只在新帧完成时刷新，聊天／输入法导致的重绘复用已有帧。隐藏、最小化和暂停阻止新任务，未完成结果会失效并释放；恢复不累计停顿时间。窗口尺寸、像素密度、画质和批次变化会使旧任务失效。缓存只保留当前帧和最多一个待准备帧。

[Flutter Picture.toImage](https://api.flutter.dev/flutter/dart-ui/Picture/toImage.html)用于异步生成图片；生产Room不再从paint调用toImageSync。同步渲染仍作为像素参考检查。异步快照和参考路径的真实模型最大逐通道像素差为1，合成模型也通过遮罩、染色、透明度、UV和混合检查。

## 辉夜快跑

背景克隆的启动帽被推迟到下一调度帧，使新克隆在第一次绘制时仍保持旧克隆的离屏位置。使用原版[Scratch调度器](https://github.com/scratchfoundation/scratch-vm/blob/develop/src/engine/sequencer.js)的同帧新线程语义，并按照[克隆及图层语义](https://github.com/scratchfoundation/scratch-vm/blob/develop/src/blocks/scratch3_control.js)维护唯一绘制顺序：克隆插在来源后方，层次移动采用有界插入。同步重开和零秒等待仍遵循原有规则。

旧版main `53350436e663c063f00a2fafa4521d1528b527ee`，背景速度7的300帧复现中，69、138、207、276帧出现右侧露底，共4次；修复后为0。新增速度7、8、11、18、24的连续性检查，覆盖背景克隆多次接续，且不修改素材。游戏运行仍按原版30Hz；120Hz屏幕不再为没有模拟变化的帧重复通知绘制，分数变化只更新分数文字，舞台与页面独立重绘。碰撞边界按角色姿态缓存，位置、缩放、方向或造型变化后重算。

下车脚本固定强制造型17直到该造型碰到地面；不同角色模型的碰撞轮廓可能永远达不到条件，导致覆盖跑步动画。改为交给既有重力／落地脚本统一管理下落和各模型造型。三种模型1、2、4从高处下车均能落地并继续播放对应跑步动画；保留骑乘、上下控制、闪光、死亡、暂停、重开及音频检查。

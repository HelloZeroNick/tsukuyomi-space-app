0.6.23+30 / v0.6.23-beta.1：Live2D 启动加载与聊天滚动修复。

- 修复滑动聊天记录、输入文字和键盘变化时主动暂停 Live2D 的问题。Android 原生 GPU 继续按所选帧率目标运行；兼容 Canvas 在交互期间最高 30 fps，保留所选画质。
- Android 启动只编译当前模型支持的 8 个官方着色器程序，省去 474 个未使用的高级混合变体；保留普通、加算、乘算、遮罩和反向遮罩。模型、物理、图集和表情资源改为并行读取。
- 保留单帧任务限流，以及隐藏页面、后台和手动暂停。角色状态增加模型加载耗时，原生探针记录初始化、解码、上传和首帧时间，便于实机定位。
- 自动档仍为 3K 图集、最高 400 万输出像素；本次未通过降低分辨率加速。其他平台继续使用 Canvas。

普通 Android 手机选择 **arm64-v8a**。安装后角色状态应显示 `Cubism GPU · OpenGL ES`。主机测试和 Android 模拟器验证不代表红米 K90 的加载秒数、帧率、温度或续航，仍需同设备体验验证。iOS 包需自签；鸿蒙补包由独立流程追加，未签名 HAP 需自行签名。

实现与验证边界见[原生 GPU 说明](https://github.com/redchenk/tsukuyomi-space-app/blob/main/docs/native-live2d-gpu.md)。
